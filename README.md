# FragCheck
CS2 FACEIT Player Statistics & Performance Analytics.

Collaborative project between JoeRenDev & Kaan-Dilmen.

## Current and Planned Features

### Current Features
- Responsive frontend.
- Search users on FACEIT database.
- View player statistics (K/D, win rate, average kills, etc).
- Specific map performance statistics.

### Planned Features
- Player profile/performance comparison.
- Login functionality.
- Player data exports.
- Security hardening.
- AI-powered performance analysis.
- AI-powered playstyle improvement suggestions.
- AI-powered realtime match analysis.

## Development Notes
- main – The stable branch containing completed, tested and approved features. Changes are merged into main once development milestones have been completed.
- development – The active development branch where new features, improvements and bug fixes are implemented and tested before being merged into main.
- API Key not included within this repository, for testing / demonstration before full deployment, an API key can be created through the 'FACEIT for Developers' portal.
