# FragCheck
CS2 FACEIT Player Statistics & Performance Analytics.

Collaborative project between JoeRenDev & Kaan-Dilmen.

## Current and Planned Features

### Current Features
- Responsive frontend
- Search users on FACEIT database
- View player statistics (K/D, win rate, average kills, etc)
- Specific map performance statistics

### Planned Features
- Player profile/performance comparison
- AI-powered performance analysis
- AI-powered playstyle improvement suggestions
- AI-powered realtime match analysis

## Third-Party Services & Disclaimer

FragCheck uses the official FACEIT Data API to retrieve player profiles and relevant data.
